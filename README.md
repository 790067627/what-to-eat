# 今天吃啥 · 微信点菜灵感小程序

个人使用的"不知道吃啥"决策工具 + 私人菜品库。微信原生小程序 + 云开发（Serverless），无服务器成本。

## 功能

- 🎲 **抽一抽**：随机抽菜，支持排除最近 N 天吃过的、只抽"想吃"、限定分类；抽中后可"记一笔"或"换一个"
- 📖 **菜品库**：分类侧栏 + 搜索 + 状态筛选（想吃/常吃/不想再吃）
- ＋ **菜品管理**：图片上传（最多9张，云存储）、分类、价格、标签、评分、介绍/做法笔记
- 🗂️ **分类管理**：增删改、排序、emoji 图标
- 🕐 **吃过时间线**：每次"记一笔"自动沉淀，随机时避免重样
- 📦 **数据导出**：一键导出全部 JSON 到剪贴板

## 技术架构

```
miniprogram/          前端（原生小程序）
├── pages/            8 个页面（4 个 tabBar + 4 个子页）
├── custom-tab-bar/   自定义 tabBar（中间凸起"抽一抽"按钮）
├── services/db.js    数据服务层（统一走云函数，前端不直连数据库）
└── utils/util.js     工具函数
cloudfunctions/dish/  唯一云函数（命令路由模式，openid 数据隔离 + 服务端校验）
experiments/          实验与验证产物（POC/原型/兼容性验证，不参与构建，详见其中 README）
```

数据库集合（云开发控制台手动创建，或首次调用自动按需创建*）：
- `categories`：分类 { name, icon, sortOrder, deleted }
- `dishes`：菜品 { name, categoryId, coverImage, images[], description, price(分), tags[], rating, status, deleted }
- `eat_logs`：吃过记录 { dishId, dishName, coverImage, note, eatenAt }

> *云开发数据库集合不会自动创建，需按下文步骤手动建 3 个集合。

## 部署上线步骤

### 1. 注册小程序（个人主体）
1. 打开 mp.weixin.qq.com → 立即注册 → 小程序
2. 主体类型选**个人**（免费，无需 300 元认证费；个人主体不能开通微信支付——本项目无支付，正好）
3. 注册完成后：设置 → 基本设置，拿到 **AppID**

### 2. 导入项目
1. 打开**微信开发者工具**（稳定版即可）
2. 导入项目 → 选择本目录 → AppID 填你的 → 后端服务选**微信云开发**
3. 把 `project.config.json` 里的 `"appid": "touristappid"` 改成你的 AppID

### 3. 开通云开发
1. 开发者工具顶部点「云开发」→ 开通（选免费额度环境即可）
2. 记下环境 ID（形如 `xxx-1a2b3c`），填到 `miniprogram/config.js` 的 `ENV_ID`（只有一个环境可留空）
3. 云开发控制台 → 数据库 → 创建 3 个集合：`categories`、`dishes`、`eat_logs`
4. 每个集合的权限设置选「**仅创建者可读写**」（所有读写走云函数，云函数用管理员权限不受限，此设置最安全）

### 4. 部署云函数
1. 开发者工具左侧目录 `cloudfunctions/dish` 上**右键 → 上传并部署：云端安装依赖**
2. 等部署完成（1-2 分钟）

### 5. 本地预览
1. 点「编译」，模拟器里应能看到首页
2. 首页点「一键载入示例数据」→ 5 个分类 + 5 道示例菜即刻可玩
3. 手机预览：点「预览」扫码，真机验证抽卡、传图、记一笔全流程

### 6. 提审发布
1. 类目选择：**工具 → 效率**（个人主体可选，无需资质；以微信官方最新类目规则为准）
2. 后台「设置 → 服务内容声明 → 用户隐私保护指引」：勾选"选中的照片或视频信息"（chooseMedia 需要）
3. 全 App 文案已按"个人菜谱记录工具"定位，无"下单/购买/外卖"等经营性词汇，个人主体审核风险低
4. 点「上传」→ 后台「版本管理」→ 提交审核（首次 1-3 个工作日）
5. 审核通过 → 点「发布」，之后自己在微信里搜小程序名即可使用

## 已知约束

- 个人主体：不能开通支付、不能选餐饮类目（本项目均已规避）
- 云函数单次查询上限 100 条，代码已做自动分批（上限 1000 条，个人使用足够）
- 图片走 `sizeType: ['compressed']` 压缩后上传，节省云存储空间
